# Dataset source and citations

Tiny ImageNet is the Stanford CS231n Tiny ImageNet Challenge dataset.
Primary source: https://cs231n.stanford.edu/2017/project.html
Original archive linked by the course:
https://cs231n.stanford.edu/tiny-imagenet-200.zip

The actual Kaggle dataset owner/version is not known before the user attaches
it. The adapter records the exact mounted path and inventory fingerprint in
outputs/dataset_source.json. Record the Kaggle dataset URL and version in the
notebook's dataset-source cell as well; they must accompany the final citation.
Do not invent a Tiny ImageNet publication, DOI or BibTeX author list.

Retain the established CIFAR citation from the current manuscript:
A. Krizhevsky, "Learning multiple layers of features from tiny images,"
University of Toronto, technical report, 2009.
Primary source: https://www.cs.toronto.edu/~kriz/cifar.html

Tiny ImageNet's labeled validation set is used as the held-out evaluation
set here. The unlabeled challenge test set is not used. No dataset is included
in this source ZIP, and no Tiny ImageNet data was downloaded to the laptop.
